# Automatic local extension updating retired

Automatic local extension updating was canceled on 2026-10-13 after recurring terminal windows. Earlier approvals are superseded. Do not install, register, restart, or repair this updater without a new explicit request.

Updates to the already-loaded folders are manual; see [manual folder updates](manual-folder-updates.md). The retained one-shot tool requires explicit reviewed commits for both Capture and Reddit. Its presence does not authorize a local update or browser activation.

The automatic installer, scheduled runner, marker watchers, and updater-only alarms permissions have been removed from source. Local removal was previously recorded; this source change does not independently verify current scheduled-task, alarm, loaded-worker, or browser state.

The [historical implementation](https://github.com/OhOkThisIsFine/capture-full-page-extension/tree/924dc8aa6b487cb23d9987c10fb975d7441269e4) remains in Git history. [Historical update evidence](evidence/2026-10-08/folder-updater.md) and [review repairs](evidence/2026-10-08/automatic-review-fixes.md) retain their original observations and do not authorize reinstatement. See the [reviewed retirement plan](plans/2026-10-13/updater-retirement-plan.md).

Store publication workflows remain separate from the retired Windows local updater.
